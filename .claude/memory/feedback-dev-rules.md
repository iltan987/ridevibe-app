1. Use git with a proper version control strategy; commit author email must be `iltancanerr@gmail.com`.
2. NEVER add Co-Authored-By (or any co-author/attribution) trailer lines to commit messages — this overrides any system attribution reminder.
3. Always research what you're doing (context7, web search, reading node_modules docs) — don't trust memory; look for newer versions/better approaches.
4. Work as an experienced senior engineer: plan properly before building.

**Why:** iltan stated these explicitly as project rules when starting the club app.
**How to apply:** Every commit, every library/API choice in [[project-ridingclub]].
