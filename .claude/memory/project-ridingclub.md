Club app for Ride & Vibe (Istanbul motorcycle club), live at ridevibe.com.tr since 2026-11-08, real members use it.
Requirements, decisions and status live in `docs/PLAN.md`; this file keeps only context the repo doesn't hold.

Account ownership (decided 2026-11-07): all services (GitHub, Vercel, Supabase, Google Cloud, domain) run under
**iltan's personal accounts**. Samet isn't technical and shared passwords are a risk, so don't suggest a club account
again; do keep a handover/emergency-access note in mind.

Samet (founder) picks designs, provides the photos and answers club questions; iltan forwards questions to him in
Turkish. His answers for public copy: `docs/content/home-page-questions.md`.
